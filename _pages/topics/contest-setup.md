The files and tools I start every problem with: starter templates for contests, LeetCode, and OI, and small scripts that create, fetch, and test a solution.

## From the Notebook {#notebook}

Implementations from my [competitive programming notebook](https://github.com/lamng3/competitive-programming-notebook), tagged with their [USACO Guide](https://usaco.guide/) level where they have one.

- **Starters**. [`contest.cpp`](https://github.com/lamng3/competitive-programming-notebook/blob/main/templates/contest.cpp): Default contest file. [`leetcode.cpp`](https://github.com/lamng3/competitive-programming-notebook/blob/main/templates/leetcode.cpp): LeetCode method stub. [`minimal.cpp`](https://github.com/lamng3/competitive-programming-notebook/blob/main/templates/minimal.cpp): Shortest starter. [`oi.cpp`](https://github.com/lamng3/competitive-programming-notebook/blob/main/templates/oi.cpp): OI starter. [`template.py`](https://github.com/lamng3/competitive-programming-notebook/blob/main/python/template.py): Python starter.
- **Tools**. [`cpnew`](https://github.com/lamng3/competitive-programming-notebook/blob/main/tools/cpnew.py): Copy a template into a new file. [`cpgen`](https://github.com/lamng3/competitive-programming-notebook/blob/main/tools/cpgen.py): Fetch a LeetCode problem and write the stub. [`cptest`](https://github.com/lamng3/competitive-programming-notebook/blob/main/tools/cptest.py): Run a solution against cached examples.
